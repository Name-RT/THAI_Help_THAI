# THAI_Help_THAI
A cross-platform micro web application designed for Thai SME sellers to generate professional and transparent price tags. This tool specifically supports the "Thai Help Thai" (ไทยช่วยไทย) policy by automating complex price calculations, ensuring both sellers and buyers have a clear understanding of the costs.

## 📋 วิธีใช้งานโปรแกรมแบบเป็นขั้นตอน (How to Use)

### 1. ตั้งค่าข้อมูลร้านค้า
* **ภาษา:** คลิกปุ่มมุมขวาบนเพื่อสลับสัญลักษณ์และข้อความระหว่าง **TH** (ไทย) หรือ **EN** (อังกฤษ)
* **ชื่อร้าน:** พิมพ์ชื่อร้านค้าของคุณในช่อง "ชื่อร้าน" (ชื่อร้านจะไปปรากฏที่แถบสีน้ำเงินด้านบนสุดของแผ่นป้ายราคา)

### 2. เพิ่มรายการสินค้าและราคาปกติ
* ในกล่อง **เพิ่มสินค้า**:
  1. พิมพ์ชื่อสินค้าในช่องแรก (เช่น *ข้าวผัดกะเพรา*, *ไข่ดาว*)
  2. พิมพ์ราคาเต็มของสินค้าในช่องที่สอง (เช่น *50*, *10*)
  3. คลิกปุ่ม **เพิ่มสินค้า**
* รายการสินค้าจะไปปรากฏทั้งบนรายการลบด้านซ้ายมือ และบนตัวอย่างแผ่นป้ายราคา A4 ด้านขวา
* หากต้องการลบสินค้า ให้คลิกไอคอนถังขยะสีแดงหน้าชื่อสินค้านั้น ๆ ในแถบควบคุมด้านซ้าย

### 3. ปรับขนาดตัวอักษรเพื่อพิมพ์
* เลื่อนแถบ **Print Font Size** เพื่อขยายหรือลดขนาดตัวอักษรบนป้ายราคาตามต้องการ (แนะนำขนาด 28px ขึ้นไปสำหรับการตั้งหน้าร้านเพื่อให้ผู้สูงอายุอ่านง่าย)

### 4. บันทึกและพิมพ์ป้ายราคา
* **บันทึกรูปภาพ (Save as Image):** ดาวน์โหลดแผ่นป้ายราคาออกมาเป็นรูปภาพไฟล์ PNG
* **บันทึกเป็นไฟล์ PDF (Save as PDF):** ดาวน์โหลดแผ่นป้ายราคาเป็นไฟล์เอกสาร PDF ขนาด A4
* **พิมพ์โดยตรง (Print):** กดคีย์บอร์ด `Ctrl + P` (บน Windows) หรือ `Cmd + P` (บน Mac) เพื่อสั่งพิมพ์ผ่านเครื่องพิมพ์ที่เชื่อมต่ออยู่ได้ทันที (ระบบจะซ่อนเมนูด้านซ้ายมือให้โดยอัตโนมัติ เหลือเพียงตัวป้ายราคาขนาด A4 สีสันคมชัด)

---

## 💡 คำแนะนำเพิ่มเติมสำหรับการพิมพ์ป้ายหน้าร้าน
- หากรายการสินค้ามีจำนวนมากจนล้นกระดาษ ระบบจะสร้างหน้า 2 (ต่อ) ให้อัตโนมัติ
- ในหน้าตั้งค่าการพิมพ์ของเบราว์เซอร์ แนะนำให้ทำเครื่องหมายที่หัวข้อ **"พิมพ์พื้นหลัง" (Print Background Graphics)** เพื่อให้ตารางราคาแสดงสีสันที่สวยงาม (สีน้ำเงิน สีแดง และสีเขียว) ครบถ้วนบนแผ่นป้ายจริง
